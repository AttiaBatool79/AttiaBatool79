##  Featured project

### [Smart Controller: ESP32-S3 IoT Relay Controller](https://github.com/AttiaBatool79/smart-controller-esp32s3)
Firmware in **C++ on ESP-IDF / FreeRTOS** for an industrial ESP32-S3 relay board.

- On-device **web dashboard + REST API** (no cloud needed)
- **Daily schedules** with NTP time, settings saved in flash (NVS)
- **MQTT** remote control and status
- **OTA firmware updates** from the browser with **automatic rollback**
- **WiFi setup portal** (the board opens its own access point)
- Own **SSD1306 OLED driver** over I2C, written from the datasheet
